# Shell is Library | player | tool pane, not three full-screen modes

The window follows an IDE shell: left Library always visible (course switcher, Session/Video tree, Settings at the bottom — no account), center player with Composer under it, right pane switched by an activity bar (Search, Ask, Summary, Notes). Full-screen modes would hide the player when a Hit arrives, and would hide the Library when recalling. The right pane may expand over the player; the left Library never swaps away. Native macOS vibrancy on the side panes; other OSes get a solid fallback, not a fake Mac.
