# Shell is Library | player | tool pane, not three full-screen modes

The window follows an IDE shell: left Library always visible, center player, right pane switches Search / Ask / Summary / Notes. Full-screen “modes” would hide the player when a Hit arrives, and would hide the Library when recalling. The Cursor/VS Code mockup is the wireframe for this shell, not a literal copy of git, plans, or prompt chrome.
